# Glosario

| Término | Significado | Ver |
|---|---|---|
| **Proceso industrial** | Conjunto ordenado de operaciones para transformar, transportar o transferir energía | [[Diagrama de proceso]] |
| **Ingeniería básica** | Etapa inicial que define el qué, con qué equipos, en qué secuencia y qué variables | [[TP1 Diagramas de proceso]] |
| **Corriente** | Flujo de material o energía entre dos puntos del proceso | [[Diagrama de proceso]] |
| **Caudal (Q)** | Cantidad de fluido por unidad de tiempo (m³/h, L/min) | [[Variables de proceso]] |
| **Presión** | Fuerza del fluido por unidad de área | [[Variables de proceso]] |
| **Presión hidrostática** | P = ρ·g·h: crece con la profundidad y la densidad | [[Tanque]] |
| **Altura manométrica (H)** | Energía por unidad de peso que la bomba entrega (en metros) | [[Bomba]] |
| **Curva del sistema** | Energía que pide la instalación según el caudal (H_est + k·Q²) | [[Bomba]] |
| **Punto de funcionamiento** | Cruce de la curva de la bomba con la del sistema | [[Bomba]] |
| **BEP** | *Best Efficiency Point*: el punto de máximo rendimiento | [[Bomba]] |
| **Cebado** | Llenar de líquido la bomba y la succión antes de arrancar | [[Bomba]] |
| **Cavitación** | Burbujas de vapor que implotan por baja presión local: ruido, vibración y erosión | [[Bomba]] |
| **Presión de vapor** | Presión por debajo de la cual el líquido hierve; sube con la temperatura | [[Bomba]] |
| **NPSHA / NPSHR** | Carga de aspiración disponible (la da la instalación) y requerida (la pide la bomba) | [[Bomba]] |
| **Variador de frecuencia (VFD)** | Regula la velocidad del motor para adaptar el caudal | [[Bomba]], [[Compresor]] |
| **Pérdida de carga** | Energía que se pierde por rozamiento (continua) o en accesorios (local, K) | [[Pérdidas de carga]] |
| **Golpe de ariete** | Sobrepresión por un cambio brusco de flujo (por ejemplo, abrir rápido una línea de vapor) | [[Cañerías y accesorios]] |
| **P&ID** | Diagrama de cañerías e instrumentos | [[P&ID]] |
| **Válvula de aislamiento / regulación / retención** | Abre o cierra del todo / ajusta / impide el retorno | [[Válvulas]] |
| **PSV / PRV** | Válvula de seguridad o alivio: automática y calibrada | [[Válvulas]], [[Recipiente a presión]] |
| **Esfuerzo circunferencial (de aro)** | σ = P·D / 2t; el doble del longitudinal en un cilindro | [[Recipiente a presión]] |
| **Cabezal** | Tapa de un recipiente: hemisférico, elíptico 2:1, torisférico o plano | [[Recipiente a presión]] |
| **MAWP** | Máxima presión de trabajo admisible del recipiente | [[Recipiente a presión]] |
| **END** | Ensayos no destructivos: RT, UT, PT, MT | [[Recipiente a presión]] |
| **Prueba hidrostática** | Prueba de presión con agua, según un procedimiento | [[Recipiente a presión]] |
| **Pitting** | Corrosión localizada por picado | [[Tanque]] |
| **Cubeto** | Muro de contención alrededor de un tanque, para derrames | [[Tanque]] |
| **Fouling** | Ensuciamiento de las superficies: menos calor y más ΔP | [[Intercambiador de calor]] |
| **Contracorriente** | Flujos opuestos: mejor transferencia | [[Intercambiador de calor]] |
| **Deflector** | Chapa que guía el flujo en la carcasa y sostiene los tubos | [[Intercambiador de calor]] |
| **Relación de compresión** | p_abs de descarga / p_abs de aspiración | [[Compresor]] |
| **Interenfriador / posenfriador** | Enfriamiento entre etapas / a la salida del compresor | [[Compresor]] |
| **FAD** | *Free Air Delivery*: caudal referido a las condiciones de aspiración | [[Compresor]] |
| **Punto de rocío a presión** | Temperatura a la que condensa el agua del aire comprimido | [[Sistema de aire comprimido]] |
| **Potencia específica** | kW por m³/min: la eficiencia de un compresor | [[Compresor]] |
| **Carga-descarga / start-stop** | Métodos de control de un compresor | [[Compresor]] |
| **FRL** | Filtro + regulador + lubricador | [[Unidad FRL]] |
| **Pirotubular / acuotubular** | Gases por los tubos / agua por los tubos | [[Caldera]] |
| **Purga** | Extracción de agua con sólidos concentrados (caldera) o de condensado (aire) | [[Caldera]] |
| **Exceso de aire** | Aire por encima del estequiométrico en la combustión | [[Caldera]] |
