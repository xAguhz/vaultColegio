## Despieces y ubicación de componentes
### Ubicación de los componentes del sistema de encendido
**1.** ECM, **2.** Conjunto de bobina de encendido para las bujías 1 y, **3.** Conjunto de bobina de encendido para las bujías 2 y, **4.** Sensor CMP (para motores con VVT), **5.** Sensor de CKP, **6.** Sensor de MAP, **7.** Sensor de ECT, **8.** Sensor de MAF e IAT, **9.** Sensor de TP, **10.** VSS, **11.** Cables de alta tensión, **12.** Sensor de detonación, **13.** Conector de enlace de datos, **14.** Caja de fusibles de la batería, **15.** Caja de relés, **16.** Conjunto del bloque de empalmes, **17.** Sensor CMP (para motores sin VVT)
