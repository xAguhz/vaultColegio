## Despieces y ubicación de componentes
### Ubicación de los componentes del sistema de control electrónico
**1.** Sensor de MAF e IAT, **2.** Sensor de TP, **3.** Interruptor de las luces de freno, **4.** Sensor de ECT, **5.** Sonda de oxígeno calentado-1, **6.** VSS, **7.** Batería, **8.** Sensor CMP (para motores con VVT), **9.** Sensor de MAP, **10.** Sensor de CKP, **11.** Sensor de nivel de combustible, **12.** Sensor de detonación
