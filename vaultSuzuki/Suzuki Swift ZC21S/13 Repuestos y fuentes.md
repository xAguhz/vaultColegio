## Repuestos de mantenimiento
Al pedir repuestos conviene dar **modelo + código de chasis + motor**: *Suzuki Swift 2008, ZC21S, M15A 1.5, automático*. Los repuestos mecánicos son los mismos que los del Swift 1.5 europeo, australiano y asiático de 2005-2010.

| Repuesto | Referencia |
| -------- | ---------- |
| Bujías de níquel | NGK BKR6E-11 · Denso K20PR-U11 (luz 1,0–1,1 mm) |
| Bujías de iridio | NGK IFR6J11 |
| Aceite de motor | API SL o superior · 5W-30 · ≈ 3,9 L con filtro |
| Fluido de caja | SUZUKI ATF 3317 o Mobil ATF 3309 · 3,3 L en un cambio |
| Refrigerante | Anticongelante de etilenglicol al 50 % · ≈ 6,1 L |
| Líquido de frenos | DOT 3 |
| Batería | 46B24R (12 V, 36 Ah), borne positivo a la derecha |
| Neumáticos | 185/60R15 84H |
| Pastillas delanteras | para disco ventilado de 20 mm (Swift 1.5 2005-2010) |
| Correa de accesorios | correa en V del M15A (alternador y bomba de agua; según si tiene aire acondicionado) |

> [!tip] Antes de comprar
> - Comparar el repuesto viejo con el nuevo: en esta generación hubo cambios menores entre años y mercados.
> - Para piezas de carrocería y ópticas, el auto japonés es **de mano derecha**: los faros tienen el corte de la luz baja hacia el otro lado y algunas piezas del tablero son distintas.

## El manual del propietario japonés (取扱説明書)
Suzuki publica sus manuales del propietario en la página oficial de **オーナーズマニュアル**: https://www.suzuki.co.jp/car/owners_manual/
1. Elegir **スイフト** (Swift) o buscar por el número de chasis (車台番号) del 車検証.
2. La página pide aceptar sus **condiciones de uso** (利用規約) antes de abrir el PDF. Entre otras cosas, prohíben copiar y redistribuir el manual: por eso **no está subido a este vault**, que es público.
3. Si no aparece la versión de 2008, consultar con un concesionario Suzuki con el número de chasis.

> [!note] Cómo se armó este vault
> No se pudo bajar el manual del propietario japonés de forma automática (la página pide aceptar las condiciones de uso). Por eso la base es el manual de taller, que cubre la misma carrocería y mecánica, más el catálogo japonés para los datos del 1.5XS. Si se consigue el PDF japonés, se pueden completar acá las presiones de neumáticos de la etiqueta y los detalles de equipamiento.
