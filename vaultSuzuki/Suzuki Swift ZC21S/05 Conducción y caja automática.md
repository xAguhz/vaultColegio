# 05 · Conducción y caja automática

Volver a [[00 Suzuki Swift ZC21S]]

El 1.5XS japonés lleva una **caja automática de 4 marchas** (transeje: caja + diferencial en una sola carcasa, al lado del motor). Tiene **convertidor de par**, trenes de **engranajes planetarios** y los cambios los decide la computadora de la caja (TCM) con válvulas solenoides.

## Posiciones de la palanca
| Posición | Qué hace |
| -------- | -------- |
| **P** (estacionamiento) | Caja en neutro y el eje de salida trabado. Se puede arrancar. Para salir de P hay que pisar el freno. |
| **R** (marcha atrás) | Retroceso. Solo con el auto parado. |
| **N** (neutro) | Sin tracción; se puede arrancar. |
| **D** (manejo) | Cambia sola entre 1ª, 2ª, 3ª y 4ª (superdirecta). Uso normal. |
| **3** | Usa de 1ª a 3ª: para subidas largas o para que frene con el motor. |
| **2** | Usa 1ª y 2ª: bajadas fuertes, barro o nieve. |
| **L** | Queda en 1ª: bajadas muy empinadas o remolque lento. |

## Arranque y salida
1. Palanca en **P**, freno pisado.
2. Dar arranque (no más de unos segundos por intento).
3. Con el freno pisado, pasar a **D** o **R**. El auto "tira" un poco solo (avance lento por el convertidor): es normal.
4. Soltar el freno y acelerar suave.

## Buenas prácticas
- **No pasar a P ni a R con el auto en movimiento**: se puede romper el trinquete de estacionamiento o la caja.
- En pendiente: primero el **freno de mano**, después pasar a **P**. Así el auto no queda colgado del trinquete.
- **No usar N para "ahorrar" en bajadas**: se pierde el freno motor y la caja se lubrica peor.
- Si el auto queda varado, **remolcarlo con las ruedas delanteras levantadas** (o en grúa de plataforma): la caja se lubrica con la bomba del motor y si el motor no gira, las ruedas delanteras no deben arrastrarla.
- Atascado en barro: no balancear entre D y R acelerando a fondo; recalienta el fluido.

## Cómo se controla el nivel
- Se mide **en caliente** (fluido a temperatura de marcha), con el auto **nivelado**, el motor **en marcha** en P, después de pasar la palanca por todas las posiciones.
- La varilla tiene marcas para frío y caliente; con el fluido caliente el nivel debe quedar entre las marcas HOT.
- Fluido marrón oscuro o con olor a quemado: falta un cambio o hay patinamiento interno.

> [!warning] Fluido correcto
> Usar **solo el ATF especificado** (3317 / 3309). Un ATF genérico de otra norma cambia la fricción de los embragues y produce golpes o patinamiento.
