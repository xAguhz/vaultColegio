El problema y la idea

Diez archivos sueltos no son un apunte

El material está desparramado entre Drive, PDF y YouTube, y para estudiar hay que acordarse de dónde estaba cada dato. La idea es que cada tema tenga su nota, y que las notas se enlacen entre sí.

Los vaults

Un vault por materia, proyecto o fuente

El mismo método funcionó con fuentes muy distintas: una carpeta de Drive, manuales técnicos en inglés y en japonés, un canal de YouTube, una materia completa y un solo video.

El método

Siete pasos, de la fuente a la web

Son los mismos para cualquier materia. El último vuelve al principio: la red se corrige y se amplía todo el año.

  1. Juntar las fuentes

    Apuntes, consignas, entregas, manuales y videos, con su nombre y su link.

  2. Pasarlas a texto

    Leer Docs y PDF, bajar subtítulos, traducir manuales, corregir errores.

  3. Partir en notas

    Una idea por nota, con resumen arriba y propiedades.

  4. Enlazar

    [[Bomba]], [[TP7]]… en las dos direcciones, sin enlaces rotos.

  5. Mapas e índices

    Una nota 00 Inicio y un Canvas por vault.

  6. Producir

    Guías de estudio, informes, presentaciones, ilustraciones, 3D.

  7. Publicar

    GitHub guarda cada cambio y la página se arma sola.

Herramientas y conectores

Casi todo es gratis y de código abierto

Lo único pago es el asistente de IA. Obsidian, GitHub y la página web se pueden usar sin costo.
