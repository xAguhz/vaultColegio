# Código pegamento

*Glue code*: pequeñas piezas de software que sirven para **pegar unos sistemas con otros**. [▶ 12:53](https://www.youtube.com/watch?v=3hxdHem70gw&t=773s)

> Una parte enorme del trabajo de integrar consiste simplemente en que A pueda hablar con B, después que B hable con C, y después que C entienda lo que devuelve A.

MHS intenta **reducir parte de ese caos** con una estructura común. Los [[Driver MHS|drivers]] siguen siendo código de integración, pero se escriben una vez por equipo y quedan con la misma forma, en vez de uno por cada par de equipos.
