# Gemini API

Acceso directo a los modelos de [[Gemini]] desde el entorno donde trabaja [[Claude Code]]. La **clave** está guardada en la configuración del entorno, nunca en el repositorio. → [[Privacidad]]

Sirve para que la IA le pida trabajos a Gemini (por ejemplo imágenes) directamente, sin que la persona tenga que copiar y pegar entre programas.
