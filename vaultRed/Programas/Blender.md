# Blender

Programa libre de modelado y animación 3D. En la red **no se usa a mano**: se le pasa un script de Python y arma todo solo, "en segundo plano".

- **Torno TM300**: modelo 3D por conjuntos (59 piezas) con las medidas del manual, exportado para el visor web. → [[torno_tm300_3d (script)|torno_tm300_3d.py]]
- **Spot de AutoLID**: la escena completa del video publicitario, cuadro por cuadro. → [[Publicidad AutoLID]]

La ventaja de hacerlo con un script es que se puede **corregir y volver a generar** cuando cambia un dato.
