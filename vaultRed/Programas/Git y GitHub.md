# Git y GitHub

- **Git** guarda el historial de cambios de una carpeta: cada versión es un *commit*, con fecha, autor y un mensaje que explica qué cambió.
- **GitHub** guarda ese historial en la nube y lo comparte. El repositorio de la red es `xaguhz/vaultColegio`.

## Cómo se usa en la red
- Todos los vaults están en **un solo repositorio**.
- Obsidian sube los cambios solo, con el plugin Obsidian Git. → [[Sincronización]]
- [[Claude Code]] trabaja sobre una copia y sube sus cambios con un mensaje claro y la línea `Co-Authored-By: Claude`, así queda registrado qué hizo la IA. → [[Trabajo con IA]]
- Cada push a `main` publica la página. → [[Publicación automática]]

## Ejemplos de mensajes de commit reales
- *Sumar vaultCharrute (Sistemas Mecánicos) al repo y a la página*
- *Visor 3D: mejor uso en celular (acostado, botones más grandes, toques)*
- *vaultCharrute: TP8 sin nombres de compañeros*
