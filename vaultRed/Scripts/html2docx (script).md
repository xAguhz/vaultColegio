# html2docx.py

**Archivo:** [`vaultCharrute/herramientas/html2docx.py`](https://github.com/xAguhz/vaultColegio/blob/main/vaultCharrute/herramientas/html2docx.py) · Python.

Convierte un informe escrito en HTML en un **documento de Word** (`.docx`) armado a mano, con carátula, salto de página y número de página. Drive lo convierte después en Google Docs sin perder el formato (importando el HTML directo, Drive ignora los saltos de página).
