# torno_tm300_3d.py

**Archivo:** [`vaultTorno/herramientas/torno_tm300_3d.py`](https://github.com/xAguhz/vaultColegio/blob/main/vaultTorno/herramientas/torno_tm300_3d.py) · Python para [[Blender]].

Construye el **modelo 3D del torno** por conjuntos con las medidas del manual (altura de centros, ancho de guías, distancia entre puntas…). Cada pieza lleva su identificador, su conjunto y su dirección de despiece. Exporta el modelo para el **visor web**, donde se puede despiezar, tocar cada pieza y ver su ficha.
