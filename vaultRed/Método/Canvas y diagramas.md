# Canvas y diagramas

Tres formas de dibujar dentro de un vault:

| | Qué es | Dónde se usa |
|---|---|---|
| **Canvas** | Tablero infinito de [[Obsidian]] con notas, textos, imágenes y flechas. Con el plugin *Advanced Canvas* suma formas de diagrama de flujo y modo presentación | Un mapa por vault: *Mapa de la materia*, *Mapa del canal*, *Mapa AutoLID*, *Mapa Torno TM300*, y el [[Mapa de la red.canvas|mapa de este vault]] |
| **Excalidraw** | Dibujo a mano alzada, editable, guardado dentro de una nota | Arquitectura del hardware de AutoLID, cadena cinemática del torno |
| **Mermaid** | Diagramas escritos como texto (flujos, líneas de tiempo) que se dibujan solos | Línea de tiempo de AutoLID, sistemas de Sistemas Mecánicos, [[02 El método paso a paso|el método]] |

## En la página web
El sitio web no entiende Canvas ni Excalidraw. [[preparar (script)|preparar.py]] los **convierte**: dibuja cada Canvas como un tablero navegable y cada Excalidraw como una imagen SVG. Mermaid lo dibuja la web directamente.

## Cuándo conviene un mapa
- Para ver **el tema entero** antes de entrar al detalle.
- Para **exponer**: el Canvas se puede presentar como diapositivas.
- Para mostrar **flujos**: el recorrido del aire o la transmisión del torno.
