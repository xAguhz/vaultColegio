# 0.1 La computadora por dentro (lo mínimo)

Esta nota es para quien usa la compu poco (el mail, alguna planilla) y se maneja más con el celular. Si ya sabés qué es una carpeta, una extensión y una ruta, pasá a [[0.2 Windows, Mac y Ubuntu]].

Todo lo que viene después (Obsidian, Claude Code) trabaja con **archivos y carpetas**. Por eso esto es lo primero.

## Archivo
Un **archivo** es un "papel" guardado en la compu. Un PDF, una foto, un documento de Word, una canción: cada uno es un archivo.

Cada archivo tiene:
- un **nombre**, por ejemplo `Planificación 2027`;
- una **extensión**, que son las letras después del punto y dicen qué tipo de archivo es:

| Extensión | Qué es | Con qué se abre |
|---|---|---|
| `.pdf` | Documento para leer o imprimir | El navegador o Adobe Reader |
| `.docx` | Documento de Word | Word o Google Docs |
| `.jpg` / `.png` | Imagen | Cualquier visor de fotos |
| `.md` | **Texto simple con formato** (Markdown) | Obsidian, el Bloc de notas, cualquier cosa |
| `.exe` / `.msi` | **Instalador** de un programa en Windows | Se ejecuta con doble clic |

> [!warning] Windows esconde las extensiones
> De fábrica, Windows muestra `Planificación` en vez de `Planificación.docx`. Para verlas, abrí el **Explorador de archivos** (el ícono de la carpeta amarilla):
> - **Windows 11**: menú **Ver → Mostrar → Extensiones de nombre de archivo**.
> - **Windows 10**: pestaña **Vista** (arriba) → tildá la casilla **Extensiones de nombre de archivo**.
>
> Conviene dejarlo activado.

Los archivos `.md` son importantes para esta guía: son **texto puro** que cualquier programa puede leer, y por eso la IA los entiende perfecto. Mis notas son todas `.md`.

## Carpeta
Una **carpeta** es una caja donde se guardan archivos (y otras carpetas). Las carpetas se meten unas dentro de otras, como cajas dentro de cajas.

## Ruta
La **ruta** es la "dirección" de un archivo: el camino de cajas hasta llegar a él.

```
C:\Users\Marta\Documents\Escuela\Planificación 2027.docx
```

Se lee así: en el disco `C:`, carpeta `Users`, carpeta `Marta`, carpeta `Documents`, carpeta `Escuela`, el archivo `Planificación 2027.docx`.

En Windows las carpetas se separan con `\`. En Mac y Ubuntu, con `/`. Es lo mismo, escrito distinto.

> [!tip] Copiar la ruta de algo
> - **Windows 11**: clic derecho sobre el archivo o la carpeta → **Copiar como ruta**.
> - **Windows 10**: mantené apretada la tecla `Shift`, hacé clic derecho → **Copiar como ruta de acceso**.
>
> Después se pega con `Ctrl + V` donde haga falta. Se usa en los niveles 3 y 4, para decirle a un programa dónde está una carpeta.

## Descargar no es instalar
- **Descargar** es traer un archivo de internet a tu compu. Normalmente queda en la carpeta **Descargas**.
- **Instalar** es ejecutar ese archivo (el instalador `.exe`) para que el programa quede en la compu y aparezca en el menú Inicio.

Para instalar un programa: lo descargás, vas a **Descargas**, le das doble clic al instalador y seguís los pasos con **Siguiente**. Si Windows pregunta "¿Querés permitir que esta aplicación haga cambios?", respondés **Sí** solo si lo bajaste de la página oficial.

> [!danger] Bajar programas solo de la página oficial
> Siempre desde la página del fabricante (por ejemplo `claude.com`, `obsidian.md`), nunca desde páginas de "descargas gratis". En la guía siempre pongo el link oficial.

## El navegador
El **navegador** es el programa para entrar a páginas web: Chrome, Edge, Firefox. Claude, Gemini y ChatGPT funcionan dentro del navegador, sin instalar nada (eso es el nivel 1).

## Cuenta y contraseña
Para usar casi todo vas a necesitar una **cuenta**: un usuario (generalmente tu mail) y una contraseña. Para esta guía conviene tener a mano:
- tu **cuenta de Google** (la del Gmail), porque con ella se puede entrar a Claude, a Gemini y a GitHub sin crear contraseñas nuevas;
- acceso a tu mail, porque muchas páginas mandan un código para confirmar que sos vos.

## Atajos que conviene saber

| Atajo (Windows) | En Mac | Qué hace |
|---|---|---|
| `Ctrl + C` | `Cmd + C` | Copiar lo seleccionado |
| `Ctrl + V` | `Cmd + V` | Pegar |
| `Ctrl + Z` | `Cmd + Z` | Deshacer lo último |
| `Ctrl + F` | `Cmd + F` | Buscar una palabra en la página |
| `Alt + Tab` | `Cmd + Tab` | Pasar de una ventana a otra |
| `Win + Shift + S` | `Cmd + Shift + 4` | Sacar una captura de una parte de la pantalla |

La captura de pantalla sirve muchísimo: se le puede pegar a la IA para que vea lo mismo que vos ("¿qué significa este error?").

> [!note] ¿Dónde queda la captura?
> Con `Win + Shift + S` la captura **no se guarda en ninguna carpeta**: queda "en memoria" (el portapapeles), lista para pegar con `Ctrl + V` en el chat, en un mail o en un documento. Si querés guardarla como archivo, tocá el aviso que aparece abajo a la derecha y después el ícono del disquete.

## Para practicar
1. Activá las extensiones en el Explorador de archivos.
2. Creá una carpeta en **Documentos** que se llame `IA`: abrí **Documentos**, clic derecho en un lugar vacío → **Nuevo → Carpeta**, escribí `IA` y apretá `Enter`. Ahí vamos a guardar todo lo de la guía.
3. Copiá la ruta de esa carpeta y pegala en un mail o en un documento, solo para ver cómo es. (Vas a ver que dice `Documents`, en inglés, aunque el Explorador diga "Documentos": es la misma carpeta.)
