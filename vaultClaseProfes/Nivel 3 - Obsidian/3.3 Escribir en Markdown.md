# 3.3 Escribir en Markdown

**Markdown** es la forma de dar formato con símbolos simples, sin botones. Se aprende en diez minutos y es exactamente lo que escriben las IA cuando responden (por eso las respuestas de Claude se pegan perfecto en Obsidian).

En modo edición ves los símbolos; con `Ctrl + E` ves el resultado.

## Lo básico

| Escribís | Se ve |
|---|---|
| `# Título` | Título grande |
| `## Subtítulo` | Título mediano |
| `### Sección` | Título chico |
| `**negrita**` | **negrita** |
| `*cursiva*` | *cursiva* |
| `==resaltado==` | ==resaltado== |
| `- elemento` | Lista con viñetas |
| `1. paso` | Lista numerada |
| `- [ ] tarea` | Casilla para tildar |
| `> cita` | Texto citado |
| `---` | Línea separadora |

## Tablas
```
| Magnitud | Unidad | Símbolo |
|---|---|---|
| Tensión | Volt | V |
| Corriente | Ampere | A |
```

No hace falta alinearlas a mano: con que estén las `|`, alcanza. O pedile a Claude: *"pasá esto a una tabla en Markdown"*.

## Recuadros (callouts)
```
> [!tip] Consejo
> Texto del consejo.

> [!warning] Cuidado
> Texto de advertencia.
```
Hay varios tipos: `note`, `tip`, `info`, `warning`, `danger`, `example`, `question`. En esta guía los uso todo el tiempo.

## Imágenes
Arrastrá una imagen (o pegala con `Ctrl + V`) adentro de la nota. Obsidian la copia al vault y escribe `![[foto.png]]`. Para que todas las imágenes vayan a una carpeta `Adjuntos`: **⚙ Configuración → Archivos y enlaces → Ubicación predeterminada para nuevos adjuntos → En la carpeta especificada** → `Adjuntos`. Para achicarla: `![[foto.png|300]]` (300 píxeles de ancho).

## Propiedades
Arriba de todo de una nota se pueden poner datos ordenados, entre dos líneas `---`:
```
---
tipo: concepto
unidad: 2
tags: [electricidad, ohm]
---
```
Sirven para buscar y filtrar ("todas las notas de la unidad 2"). Al principio no hacen falta. En mis vaults Claude las completa solo.

## Código o texto para copiar
Lo que va entre tres comillas invertidas (<code>```</code>) se ve en un recuadro gris con botón de copiar. Lo uso para los pedidos a la IA, como en [[1.4 Recetas para docentes]].
