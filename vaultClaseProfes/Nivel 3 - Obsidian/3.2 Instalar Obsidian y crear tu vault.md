# 3.2 Instalar Obsidian y crear tu vault

## Instalar en Windows (5 minutos)

1. Entrá a **[obsidian.md](https://obsidian.md)** y tocá **Download** (Descargar).
2. Elegí **Windows** → se descarga un archivo `Obsidian-x.x.x.exe` en tu carpeta **Descargas**.
3. Doble clic en el archivo. Si Windows pregunta si permitís que haga cambios, **Sí** (lo bajaste de la página oficial; ver [[0.1 La computadora por dentro (lo mínimo)]]).
4. Se instala solo y se abre.

> [!info] En Mac y en Ubuntu
> - **Mac**: misma página → se descarga un `.dmg` → abrirlo y arrastrar Obsidian a la carpeta **Aplicaciones**.
> - **Ubuntu**: misma página → el `.AppImage` (se ejecuta sin instalar) o el `.deb` (se instala con doble clic).

## Ponerlo en castellano
La primera pantalla está en inglés. Abajo a la izquierda, el **engranaje ⚙** (*Settings*) → **General** → **Language** → **Español**. Pide reiniciar: **Relaunch**.

## Crear tu primer vault

1. En la pantalla de bienvenida: **Crear nueva bóveda** (*Create new vault*).
2. **Nombre**: algo claro, por ejemplo `Electrotecnia 4`.
3. **Ubicación**: **Explorar** → elegí la carpeta `Documentos\IA` que creaste en el nivel 0 (si no, cualquier carpeta que encuentres fácil).
4. **Crear**.

Obsidian crea la carpeta `Documentos\IA\Electrotecnia 4` y la abre. Todo lo que escribas va a quedar ahí adentro como archivos `.md`.

> [!warning] Cuidado con OneDrive
> Muchas compus con Windows guardan **Documentos** en OneDrive sin avisar. Funciona, pero a veces OneDrive "duplica" archivos cuando se edita desde dos lugares. Si ves archivos con nombres raros como `nota-PC-de-Marta.md`, es eso. Para empezar no es grave.

## La pantalla

```
┌──────────────┬─────────────────────────────────┬──────────────┐
│ 📁 Archivos  │  # Mi primera nota              │ Links        │
│  00 Inicio   │                                 │ entrantes    │
│  Conceptos/  │  Texto de la nota…              │              │
│   Ohm        │                                 │ Esquema      │
│              │                                 │ (títulos)    │
│ ⚙            │                                 │              │
└──────────────┴─────────────────────────────────┴──────────────┘
```

| Parte | Para qué |
|---|---|
| **Panel izquierdo** | Las carpetas y notas del vault. Clic derecho → **Nueva nota** o **Nueva carpeta** |
| **Centro** | La nota abierta. Se escribe directo |
| **Panel derecho** | Qué notas apuntan a esta (*links entrantes*) y el índice de títulos |
| `Ctrl + O` | Buscar una nota por nombre y abrirla |
| `Ctrl + Shift + F` | Buscar una palabra en todas las notas |
| `Ctrl + E` | Cambiar entre **editar** y **leer** |

## Primera nota
1. Clic derecho en el panel izquierdo → **Nueva nota**.
2. Escribí el nombre arriba: `00 Inicio`. (El `00` hace que quede primera en la lista.)
3. Escribí debajo: *Este es el vault de mi materia.* No hay que guardar: **Obsidian guarda solo**, en cada letra.

## En el celular
Hay app gratis de Obsidian para **Android** y **iPhone**. Yo la uso con mis vaults sincronizados: puedo leer y corregir notas desde el celular. Para tener **las mismas notas** en la compu y en el celular hace falta sincronizar; eso está en el nivel 5.

## Para practicar
Instalá Obsidian, ponelo en castellano y creá el vault de tu materia con una nota `00 Inicio`.
