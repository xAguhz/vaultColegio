# 4.7 Anexo: Claude Code en la terminal

Todo lo de este nivel se puede hacer con la app. Este anexo es para quien quiera usar Claude Code desde la **terminal**: la ventana donde se le dan órdenes a la compu escribiendo. Es lo mismo, sin botones, y en algunas cosas es más rápido.

## Abrir la terminal en Windows
Tecla `Win` → escribí **PowerShell** → abrí **Windows PowerShell**. Aparece una ventana con algo como:

```
PS C:\Users\Marta>
```

Eso es el **prompt**: te dice en qué carpeta estás (`C:\Users\Marta`) y espera una orden.

## Instalar Claude Code
Copiá esta línea, pegala en PowerShell (clic derecho pega) y apretá `Enter`:

```powershell
irm https://claude.ai/install.ps1 | iex
```

Baja e instala Claude Code. **No hace falta ser administrador.** Cuando termina, cerrá PowerShell y abrilo de nuevo.

> [!info] En Mac y en Ubuntu
> Se abre la **Terminal** y se pega:
> ```bash
> curl -fsSL https://claude.ai/install.sh | bash
> ```

## Usarlo
1. Andá a la carpeta del vault con `cd` (*change directory*). Si la ruta tiene espacios, va entre comillas:
   ```powershell
   cd "C:\Users\Marta\Documents\IA\Electrotecnia 4"
   ```
   (Truco: escribí `cd ` y **arrastrá la carpeta** desde el Explorador a la ventana: se pega la ruta.)
2. Escribí `claude` y `Enter`.
3. La primera vez pide **iniciar sesión**: se abre el navegador, entrás con tu cuenta y volvés.
4. Ya está: escribís pedidos igual que en la app.

## Comandos y teclas útiles

| Qué | Para qué |
|---|---|
| `/help` | Lista de comandos |
| `/model` | Cambiar de modelo (Opus, Sonnet, Haiku) |
| `/memory` | Ver y editar la memoria y el `CLAUDE.md` |
| `/init` | Que Claude cree un `CLAUDE.md` para la carpeta, a partir de lo que encuentra |
| `/clear` | Empezar una conversación nueva en la misma carpeta |
| `Shift + Tab` | Cambiar el modo de permisos ([[4.3 Permisos - qué aprobar y qué no]]) |
| `Esc` | Frenar a Claude en lo que está haciendo |
| `Esc` dos veces | Volver a un mensaje anterior y reescribirlo |
| `claude --continue` | (al abrir) Seguir la última conversación de esa carpeta |
| `/exit` o `Ctrl + C` dos veces | Salir |

## ¿App o terminal?
- **App**: más amigable, se ven los cambios con colores, botones para aprobar. **Recomendada para empezar.**
- **Terminal**: más rápida para quien escribe mucho, y funciona en cualquier compu (también por conexión remota). Muchas guías de internet la usan, así que conviene saber que existe.

Las dos usan la **misma cuenta, la misma memoria y las mismas skills**.
