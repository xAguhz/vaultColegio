# 4.2 Instalar la app y abrir Code

La forma más simple de usar Claude Code es la **app de escritorio de Claude**: la misma cuenta que usás en la web, pero instalada, con una pestaña **Code**. No hay que escribir comandos. Es la que uso yo.

## Instalar en Windows (10 minutos)

1. Entrá a **[claude.com/download](https://claude.com/download)** y bajá la versión para **Windows**. (Si tu compu es de las nuevas con procesador ARM, elegí la versión **ARM64**; si no sabés, es la común.)
2. Abrí el instalador desde **Descargas** y seguí los pasos.
3. Abrí **Claude** desde el menú Inicio e **iniciá sesión** con la misma cuenta de [[1.1 Crear la cuenta y elegir el plan|la web]].
4. Arriba vas a ver pestañas, entre ellas **Chat** (lo mismo que la web) y **Code**. Tocá **Code**.

> [!info] En Mac y en Ubuntu
> - **Mac**: misma página, se baja un `.dmg` y se arrastra a **Aplicaciones**.
> - **Ubuntu**: hay versión para Linux (en *beta*, es decir, todavía en prueba). Es la que uso yo.

> [!tip] Programas que conviene tener
> - **Git para Windows** (recomendado): según la documentación de Claude Code es opcional, pero conviene instalarlo desde el principio. Claude lo usa para varias cosas (trabajar en copias aisladas, publicar en el nivel 5) y trae *Git Bash*, que necesitan algunos programas. [git-scm.com](https://git-scm.com) → **Download for Windows** → instalar con todas las opciones por defecto.
> - **Python**: solo si Claude te lo pide (por ejemplo, para generar un Word desde las notas). Ojo: en Windows, escribir `python` en la terminal abre la Microsoft Store; es mejor dejar que Claude te guíe con la instalación desde [python.org](https://www.python.org).
> - Si algo de esto falta, Claude normalmente lo detecta y te dice qué instalar.

## La primera sesión

Debajo del cuadro de texto de la pestaña **Code** hay varios controles:

| Control | Qué elegir |
|---|---|
| **Entorno** | **Local** (tu compu). La opción *Cloud* corre en servidores de Anthropic; no la necesitás |
| **Carpeta** | La carpeta donde va a trabajar Claude: elegí **el vault de tu materia** (`Documentos\IA\Electrotecnia 4`) |
| **Modo de permisos** | Para empezar, **Aceptar ediciones**. Ver [[4.3 Permisos - qué aprobar y qué no]] |
| **Modelo** | **Sonnet** para el día a día; **Opus** para trabajos grandes. Ver [[0.5 Qué IA elegir]] |

Primer pedido, para probar sin riesgo:

```
Leé todas las notas de esta carpeta y contame qué hay, qué falta
y qué me recomendarías agregar para que sea un buen vault de la materia.
No modifiques nada todavía.
```

Vas a ver a Claude **trabajando**: aparecen líneas como "Leyendo 00 Inicio.md…" o "Buscando archivos…". Al final responde con un resumen.

## Cómo se ve lo que hace
- **Pasos**: cada acción (leer, buscar, escribir) aparece como una línea que se puede abrir para ver el detalle.
- **Cambios**: cuando modifica archivos aparece una tarjeta con los archivos tocados y cuántas líneas cambió (`+12 −1`). Tocándola ves **qué cambió**, en verde lo agregado y en rojo lo borrado.
- **Detener**: si ves que va para cualquier lado, tocá el botón de **stop** (o `Esc`) y corregilo con un mensaje.
- **Obsidian abierto al lado**: las notas que crea Claude aparecen al instante en Obsidian. Es la mejor forma de revisar.

## Para practicar
Instalá la app, abrí **Code**, elegí la carpeta de tu vault del nivel 3 y hacé el pedido de prueba de arriba.
