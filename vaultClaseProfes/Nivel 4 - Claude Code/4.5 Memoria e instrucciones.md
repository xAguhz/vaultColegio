# 4.5 Memoria e instrucciones

Cada sesión de Claude Code **empieza de cero**: no se acuerda de la anterior. Para que no tengas que repetirle todo, hay dos sistemas. Los dos son **archivos de texto** que podés abrir y corregir.

| | **Memoria automática** | **CLAUDE.md** |
|---|---|---|
| Quién lo escribe | **Claude**, a partir de lo que le decís y corregís | **Vos** (o Claude, si se lo pedís) |
| Qué tiene | Cosas que aprendió: preferencias, datos de tus proyectos, errores que no hay que repetir | Instrucciones fijas para una carpeta |
| Dónde está | En la carpeta de configuración de Claude (`C:\Users\TU-USUARIO\.claude\projects\…\memory\`) | Un archivo `CLAUDE.md` adentro de la carpeta del proyecto |
| Cuándo se lee | Al empezar cada sesión | Al empezar cada sesión en esa carpeta |

## La memoria automática: cómo la uso yo
Yo trabajo casi solo con la **memoria automática**. Tiene una docena de recuerdos: una nota corta por tema. Algunos ejemplos reales:

- **Idioma**: "hablarle siempre en castellano rioplatense, también en los avisos y los botones". Lo guardó el día que me quejé porque varios mensajes salieron en inglés.
- **Dónde está cada vault** y qué tiene: el del torno, el de Charrute, el de El Profe Juanito…
- **Cómo se publica la página**, y lo que ya falló una vez (por ejemplo, que los links con carpeta se rompen al publicar).
- **Método de trabajo del grupo** para los TP de Charrute.
- **Esta guía**: las decisiones que tomamos con el grill-me (es para Windows, va en primera persona, la exposición es el jueves…).

Cada recuerdo dice **qué** es, **por qué** se guardó y **cómo aplicarlo**. Así, si mañana abro una sesión nueva y le pido "seguí con la guía de los profes", Claude ya sabe dónde está, cómo es y qué falta.

### Cómo se maneja
- **Que guarde algo**: *"Acordate de que mis alumnos de 4.° no vieron trigonometría"*.
- **Que olvide algo**: *"Olvidate de lo que guardaste sobre…"*, o borrá el archivo.
- **Ver qué recuerda**: *"¿Qué tenés guardado en la memoria sobre mí?"*.

> [!warning] Revisala de vez en cuando
> Un recuerdo viejo o equivocado hace que Claude se equivoque siempre igual. Si notás que insiste con algo que ya no es así, pedile que revise la memoria.

## CLAUDE.md: instrucciones fijas de una carpeta
Es un archivo de texto en la carpeta del vault con las reglas de ese proyecto. Para crearlo, pedí:

```
Creá un CLAUDE.md en esta carpeta con las reglas de este vault:
para qué materia y curso es, la estructura de carpetas, el tono,
que los links van sin carpeta y que la carpeta Fuentes no se toca.
```

Conviene cuando **otra persona** (un colega con el que compartís la materia) va a trabajar en la misma carpeta, o cuando tenés reglas largas y precisas. Si trabajás solo, la memoria automática alcanza.

## Para practicar
Al terminar una sesión de trabajo en tu vault, pedí: *"Guardá en la memoria lo importante de este vault para la próxima vez"*. Al día siguiente, abrí una sesión nueva y preguntá: *"¿Qué sabés de este vault?"*.
