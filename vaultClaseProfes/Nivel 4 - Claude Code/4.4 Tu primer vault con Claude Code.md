# 4.4 Tu primer vault con Claude Code

El proyecto de este nivel: que Claude arme **el vault de tu materia** a partir de tu propio material. Es lo mismo que hice yo con cada uno de mis vaults.

## Antes de empezar
1. En la carpeta del vault (la del nivel 3), creá una carpeta `Fuentes` y poné adentro tu material: el **programa**, la **planificación**, tus **apuntes**, evaluaciones viejas y capítulos de libros en PDF.
2. Abrí **Obsidian** con ese vault, y al lado la app de Claude en **Code**, con la misma carpeta elegida.
3. Elegí el modelo **Opus** (es un trabajo grande) y el modo **Aceptar ediciones**.

## Dos formas de arrancar (yo uso las dos)

### A. Que te pregunte primero (grill-me)
Es como armé **esta guía**. Sirve cuando todavía no tenés del todo claro qué querés:

```
Quiero armar en esta carpeta un vault de Obsidian para mi materia, [MATERIA] de [AÑO] año,
a partir de lo que hay en la carpeta Fuentes.
Antes de escribir nada, leé las fuentes y haceme todas las preguntas que necesites:
para quién es (para mí, para los alumnos o para los dos), qué estructura conviene,
qué nivel de detalle, qué tono. Preguntame de a pocas preguntas por vez.
```

Claude lee todo y empieza a preguntar. Contestás, vuelve a preguntar, y recién cuando no le quedan dudas arranca.

### B. Directo, con todo el contexto
Sirve cuando ya sabés lo que querés. Es como arranco los TP: le doy las fuentes y un pedido largo y detallado.

```
Armá en esta carpeta un vault de Obsidian para [MATERIA] de [AÑO] año, a partir de Fuentes.

Estructura:
- 00 Inicio: presentación y links a todo.
- 01 Guía de estudio: preguntas de repaso por unidad, con respuestas.
- 02 Glosario: tabla de términos.
- Unidades/: una nota por unidad del programa, con links a sus conceptos.
- Conceptos/: una nota por concepto, corta, con definición, explicación con un ejemplo
  del taller, fórmula si corresponde y errores comunes de los alumnos.
- Mapa de la materia.canvas: mapa con las unidades y sus conceptos.

Reglas:
- Castellano rioplatense, con "vos", para alumnos de [EDAD] años.
- Links entre notas solo con el nombre (sin carpeta). Nombres de nota únicos.
- Usá solo lo que está en Fuentes. Si algo falta o es dudoso, marcalo con (?)
  y anotalo en una lista al final de 00 Inicio.
- No toques la carpeta Fuentes.

Cuando termines, decime qué notas creaste y qué quedó dudoso.
```

## Mientras trabaja
- Mirá Obsidian: las notas van apareciendo. Abrí algunas mientras Claude sigue.
- Si algo no te gusta, **no esperes al final**: escribile en ese momento (*"las notas de Conceptos están muy largas, que no pasen de media pantalla"*). Claude ajusta lo que viene.

## Al terminar: revisar
1. Leé **00 Inicio** y la lista de dudas.
2. Abrí **al azar** tres notas de Conceptos y revisalas como profe: ¿está bien? ¿así lo explicarías? ([[1.5 Revisar lo que responde]]).
3. Abrí el **grafo** (`Ctrl + G`): ¿hay notas sueltas sin links?
4. Pedí correcciones en el mismo chat:
   ```
   Revisé el vault. Corregí esto:
   - En "Potencia eléctrica" la fórmula de trifásica está mal: es √3 · U · I · cos φ.
   - Las notas de la unidad 3 usan "voltaje": en la materia decimos "tensión". Cambialo en todo el vault.
   - Agregá a cada unidad una sección "Para practicar" con 3 ejercicios.
   ```

> [!tip] Cambios en todo el vault de una vez
> Lo que con el chat era imposible, acá es un pedido: *"cambiá 'voltaje' por 'tensión' en todas las notas"*, *"agregá a cada concepto un link a su unidad"*, *"revisá que ningún link esté roto"*.

## Seguir usándolo
El vault no se termina: cada vez que des una clase nueva o armes una evaluación, abrí Claude Code en la carpeta y pedí *"agregá al vault lo de la clase de hoy: [lo que diste]"*. Con el tiempo es el apunte completo de tu materia, hecho a tu manera.

## Para practicar
Hacé el proyecto con **una sola unidad** de tu materia, con la forma **A** (que te pregunte). Revisá el resultado y pedí al menos tres correcciones.
