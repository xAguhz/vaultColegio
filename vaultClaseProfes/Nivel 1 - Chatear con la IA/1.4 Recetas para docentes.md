# 1.4 Recetas para docentes

Pedidos listos para copiar y pegar. Lo que está entre `[corchetes]` lo cambiás por lo tuyo. Están separados en **materias técnicas** y **materias teóricas**, pero casi todos sirven para cualquiera.

> [!tip] Guardá las que más uses
> Copialas a un documento o, mejor, a una nota de Obsidian (nivel 3). En el nivel 4 se convierten en **skills**: Claude las aplica solo, sin que las pegues.

## Para cualquier materia

### Consigna clara
```
Reescribí esta consigna para que un alumno de [año] la entienda sin preguntarme nada.
Usá pasos numerados, marcá qué tiene que entregar y en qué formato, y la fecha.
Consigna original: [pegar]
```

### Rúbrica
```
Armá una rúbrica para evaluar [trabajo] de alumnos de [año].
Criterios: [lista, o "proponelos vos"]. Cuatro niveles (excelente, bueno, suficiente,
insuficiente) con una descripción concreta de cada uno, y puntaje total de 10.
En formato tabla.
```

### Ejercicios con variantes (para que no se copien)
```
Armá [N] versiones distintas del mismo ejercicio sobre [tema], con distintos valores
pero la misma dificultad. Para cada versión, la resolución completa al final.
```

### Adaptar un texto
```
Adaptá este texto para [alumnos de 1.° año / un alumno con dificultades de lectura /
leer en voz alta en 3 minutos]. Mantené los conceptos clave: [lista].
Texto: [pegar]
```

### Preguntas de repaso
```
Con este material, armá 10 preguntas de repaso: 4 de memoria, 4 de comprensión
y 2 de aplicación a un caso. Con las respuestas esperadas aparte.
Material: [pegar]
```

### Devolución a un trabajo (sin nombres)
```
Esta es la respuesta de un alumno a la consigna [pegar consigna].
Respuesta: [pegar, SIN el nombre del alumno].
Escribí una devolución breve: qué hizo bien, qué le falta y una pregunta
que lo haga pensar. Tono amable y directo, en castellano con "vos".
```

### Planificación
```
Armá la planificación de una secuencia de [N] clases de [minutos] sobre [tema]
para [año]. Para cada clase: objetivo, actividades con tiempos, recursos
y cómo evalúo si aprendieron. Tené en cuenta que contamos con [recursos].
```

## Materias técnicas (taller, electricidad, mecánica, automatización)

### Caso de falla para diagnosticar
```
Inventá un caso realista de falla en [equipo: un compresor / un motor trifásico /
un circuito electroneumático] para alumnos de [año]. Dame el síntoma que ve el operario,
3 pistas que se van dando de a una, la causa real y el diagnóstico ordenado
(de lo más simple y barato a lo más complejo).
```

### Explicar un plano o esquema
```
[Adjuntar foto del plano o esquema]
Explicá este [plano / esquema eléctrico / circuito neumático] parte por parte,
como para un alumno que lo ve por primera vez. Después, armá 5 preguntas sobre él.
```

### Traducir un manual
```
[Adjuntar PDF o foto]
Traducí esta página del manual al castellano técnico que se usa en Argentina
(por ejemplo: "rodamiento", no "cojinete de bolas"; "llave", no "interruptor").
Mantené los valores y las unidades tal cual.
```

### Hoja de seguridad del taller
```
Armá una hoja de normas de seguridad para usar [máquina] en el taller de la escuela,
para pegar al lado de la máquina. Máximo 10 puntos, frases cortas, con los
elementos de protección obligatorios al principio.
```

## Materias teóricas (Lengua, Historia, Inglés, Ciudadanía...)

### Debate
```
Proponé un debate para [año] sobre [tema]. Dame la pregunta disparadora,
3 argumentos a favor y 3 en contra con fuentes reales que pueda verificar,
y una consigna de cierre escrita.
```

### Personaje histórico
```
Escribí una "entrevista" ficticia a [personaje] sobre [hecho], basada en
hechos documentados. Marcá con [*] lo que sea interpretación y no dato.
Después, 5 preguntas para que los alumnos distingan hecho de opinión.
```

### Corrección de un texto
```
Corregí este texto de un alumno de [año]. No lo reescribas: marcá los errores
(ortografía, puntuación, coherencia) y explicá cada uno en una línea,
para que el alumno los corrija solo.
Texto: [pegar, sin nombre]
```

### Inglés técnico
```
Armá una actividad de inglés técnico para [año] con un texto corto sobre [tema técnico
de la especialidad], un glosario de 10 palabras y 5 preguntas de comprensión.
```

## Para practicar
Elegí **dos recetas** que te sirvan para la semana que viene y usalas con un tema real. Anotá qué tuviste que corregir de la respuesta.
