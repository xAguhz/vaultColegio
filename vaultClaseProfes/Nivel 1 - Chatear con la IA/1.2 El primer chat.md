# 1.2 El primer chat

## La pantalla

```
┌───────────────┬──────────────────────────────────────────┐
│ + Nuevo chat  │                                          │
│               │         ¿Cómo puedo ayudarte hoy?        │
│ Chats         │                                          │
│  · Rúbrica…   │   ┌──────────────────────────────────┐   │
│  · Ohm…       │   │ Escribí acá…                     │   │
│               │   │ [+]  [modelo ▾]            [↑]   │   │
│ Proyectos     │   └──────────────────────────────────┘   │
│               │                                          │
│ Tu nombre ⚙   │                                          │
└───────────────┴──────────────────────────────────────────┘
```

| Parte | Para qué sirve |
|---|---|
| **+ Nuevo chat** | Empezar una conversación nueva, desde cero |
| **Chats** (a la izquierda) | El historial: todas tus conversaciones anteriores, para retomarlas |
| **Cuadro de texto** | Donde escribís el pedido. `Enter` envía; `Shift + Enter` baja de renglón sin enviar |
| **[+]** | Adjuntar archivos, fotos o capturas (nivel 2) |
| **[modelo ▾]** | Elegir el modelo (Opus, Sonnet, Haiku). Ver [[0.5 Qué IA elegir]] |
| **[↑]** | Enviar |

## Primer pedido

Escribí esto (cambiando la materia por la tuya) y apretá `Enter`:

```
Soy profe de [tu materia] en una escuela técnica. Mañana tengo que explicar
[un tema que des] a alumnos de [año]. Proponeme tres formas distintas de
arrancar la clase en los primeros 5 minutos para que se enganchen.
```

Claude va a escribir la respuesta de a poco, como si tipeara. Esperá a que termine.

## La conversación sigue

Lo más importante del chat: **no es un buscador**. No hace falta que el primer pedido sea perfecto, porque podés seguir hablando y Claude recuerda todo lo que se dijo **en esa conversación**.

Probá seguir con:

```
Me gusta la segunda. Desarrollala: qué digo, qué pregunto y qué escribo en el pizarrón.
```

Y después:

```
Hacela más corta, y con un ejemplo que tenga que ver con algo de la casa.
```

> [!tip] Cuándo empezar un chat nuevo
> - **Mismo tema** → seguí en la misma conversación.
> - **Tema nuevo** → **Nuevo chat**. Si mezclás temas, Claude se confunde y gasta más límite de uso, porque relee toda la conversación con cada mensaje.

## Botones de cada respuesta

Debajo de cada respuesta aparecen íconos chiquitos:
- **Copiar**: copia la respuesta con su formato, para pegarla en Word o Docs.
- **Reintentar**: pide otra versión de la misma respuesta.
- **Editar** (en tu mensaje, el lápiz): cambiás lo que habías pedido y Claude responde de nuevo desde ahí.

## Artifacts: cuando la respuesta es "un documento"

Si pedís algo grande (una planilla de ejercicios, un juego para la clase, un documento), Claude a veces lo abre en un **panel aparte a la derecha**, llamado *Artifact*. Se puede copiar, descargar o seguir modificando por chat ("agregale una columna de puntaje").

## Para practicar
1. Hacé el primer pedido de arriba con tu materia.
2. Seguí la conversación al menos tres veces, corrigiendo lo que no te sirva.
3. Abrí un **Nuevo chat** y pedí: *"Explicame qué es un modelo de lenguaje en tres renglones, para un alumno de 15 años"*. Compará con lo que escribiste en el ejercicio de [[0.3 Qué es la inteligencia artificial]].
