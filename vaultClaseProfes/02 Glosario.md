# Glosario

Todas las palabras raras de la guía, en orden alfabético. Si encontrás una que no está, avisame.

| Palabra | Qué significa |
|---|---|
| **Agente** | IA que además de responder **hace cosas**: abre y crea archivos, busca en internet, ejecuta programas. Claude Code es un agente. |
| **Alucinación** | Cuando la IA inventa un dato y lo dice como si fuera cierto. |
| **Anthropic** | La empresa que hace Claude. |
| **Artifact** | Panel aparte donde Claude muestra un documento, una página o un programa que creó en el chat. |
| **Blender** | Programa gratuito de modelado 3D. Claude lo maneja escribiendo programas que arman las piezas. |
| **Canvas** | En Obsidian, una pizarra donde se ubican notas y flechas libremente, como un mapa conceptual. |
| **Carpeta** | Caja donde se guardan archivos y otras carpetas. |
| **Claude** | La IA de Anthropic que uso para todo. |
| **Claude Code** | Claude trabajando dentro de tu compu, sobre tus carpetas. Se usa desde la app de Claude o desde la terminal. |
| **CLAUDE.md** | Archivo de texto con instrucciones que Claude Code lee cada vez que trabaja en una carpeta. |
| **Conector** | Permiso para que Claude use otro servicio: Google Drive, Gmail, el navegador, Blender. |
| **Contexto** | Todo lo que la IA tiene a la vista en una conversación. Tiene un tamaño máximo. |
| **Excalidraw** | Plugin de Obsidian para hacer dibujos y diagramas a mano alzada. |
| **Extensión** | Las letras después del punto en el nombre de un archivo (`.pdf`, `.md`) que dicen qué tipo de archivo es. |
| **Fecha de corte** | Hasta cuándo llega lo que la IA "leyó" al entrenarse. |
| **Gemini** | La IA de Google. La uso para generar imágenes. |
| **Git** | Programa que guarda el historial de cambios de una carpeta, como un "control de versiones". |
| **GitHub** | Página donde se guardan carpetas con Git en internet. Ahí está mi vault. |
| **glTF / GLB** | Formato de archivo para modelos 3D que se pueden ver en una página web. |
| **Grafo** | En Obsidian, el mapa de puntos y líneas que muestra cómo se conectan todas las notas. |
| **Instalador** | Archivo (`.exe` o `.msi` en Windows) que pone un programa en la compu. |
| **Link (enlace)** | En Obsidian, una conexión entre dos notas. Se escribe `[[Nombre de la nota]]`. |
| **Links entrantes** | En Obsidian, la lista de notas que apuntan a la que estás leyendo. |
| **Markdown** | Forma de escribir texto con formato usando símbolos simples: `# Título`, `**negrita**`, `- lista`. Los archivos `.md`. |
| **MCP** | La forma técnica en que se conectan los conectores a Claude (*Model Context Protocol*). |
| **Memoria** | Notas que Claude guarda sobre vos y tu forma de trabajar, para no repetírselas cada vez. |
| **Modo de permisos** | En Claude Code, cuánto puede hacer Claude sin preguntarte: Manual, Aceptar ediciones, Plan o Auto. |
| **Modelo** | El "cerebro" entrenado de la IA. Opus, Sonnet y Haiku son modelos de Claude. |
| **Modelo de lenguaje (LLM)** | Programa entrenado con muchísimo texto que predice cómo sigue un texto. Claude, ChatGPT y Gemini lo son. |
| **Navegador** | Programa para entrar a páginas web: Chrome, Edge, Firefox. |
| **Obsidian** | Programa gratuito de notas en Markdown, conectadas entre sí. |
| **Plan** | El tipo de suscripción de Claude: Free, Pro, Max, Ultra. |
| **Plugin (complemento)** | Agregado que suma funciones a un programa, como Obsidian Git o Excalidraw en Obsidian. |
| **PowerShell** | La terminal de Windows. |
| **Propiedades** | Datos ordenados arriba de una nota de Obsidian (tipo, unidad, etiquetas), entre dos líneas `---`. |
| **Prompt** | El pedido que le escribís a la IA. |
| **Proyecto** | En Claude, un espacio con archivos e instrucciones fijas que se usan en todas las conversaciones de ese proyecto. |
| **Quartz** | Programa que convierte un vault de Obsidian en una página web. |
| **Rúbrica** | Tabla que dice qué se evalúa en un trabajo y qué hace falta para cada nota (por ejemplo: excelente, bien, a mejorar). |
| **Sesgo** | Cuando la IA repite siempre la misma mirada (la que más aparece en lo que leyó) como si fuera la única. |
| **Repositorio** | Carpeta guardada con Git, por ejemplo en GitHub, con todo su historial de cambios. |
| **Ruta** | La "dirección" de un archivo: `C:\Users\Marta\Documents\IA\nota.md`. |
| **Sistema operativo** | El programa principal de la compu: Windows, macOS, Ubuntu. |
| **Skill** | Receta guardada que Claude sigue para hacer siempre igual una tarea. |
| **Syncthing** | Programa gratuito que mantiene una carpeta igual en varios dispositivos (compu y celular), sin pasar por una nube. |
| **Terminal** | Ventana donde se le dan órdenes a la compu escribiendo comandos, en vez de hacer clic. |
| **Token** | Pedacito de texto (aproximadamente 3 o 4 letras) con el que la IA cuenta lo que lee y escribe. |
| **Ubuntu** | Sistema operativo gratuito, una versión de Linux. |
| **Vault** | En Obsidian, la carpeta donde están todas tus notas. Esta guía es un vault. |
