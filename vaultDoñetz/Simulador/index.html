Esquema neumático

Línea azul gruesa: con presión. Línea gris fina: sin presión. Clic en 0S1 para pulsar y en 0S2 o 0V0 para accionarlos; pasá el cursor (o tocá) cada símbolo para ver qué hace.

Deslizá el esquema y el diagrama hacia los costados para verlos completos.

Diagrama espacio-fase

Color claro: recorrido teórico. Color fuerte: recorrido real. Línea roja: fase actual.

Vista 3D

Cargando vista 3D…

Arrastrá para girar, rueda o pellizco para acercar. Con «Corte» ves las cámaras: azul = presión, gris = escape.

Elegí qué señal alimenta cada piloto. Los rodillos reciben aire de la red (directo) o de las líneas L1/L2 (cascada). Después tocá «Verificar».

Para docentes: activá una falla, ocultá el panel y dejá que el grupo la diagnostique mirando el esquema, el diagrama y la vista 3D.

En el método intuitivo no existen las líneas L1 y L2: la fuga en L2 no tiene efecto. Pasá a «Método cascada».
